# M2: Incremental build graph
Difficulty: medium

Implement buildgraph.py, class BuildGraph.
BuildGraph(dependencies): dependencies is a dict[str,list[str]]; insertion order of keys defines permanent node rank for this graph version. A listed dependency d of n means d must build before n. Duplicate dependencies count once. Unknown dependencies, non-string IDs, wrong container types, or any cycle (including self-loop) raise ValueError. Empty graph and empty IDs valid. Do not retain caller-owned mutable objects. replace(dependencies) atomically validates and replaces the full graph and its rank; returns None. On failure the previous graph remains fully usable and unchanged. Replacements need not preserve the old node set/rank.
plan(changed, targets=None) returns list[str]. changed is a one-shot iterable of node IDs; targets if not None is a one-shot iterable of node IDs. Reject unknown IDs with ValueError in either iterable, even if they would be irrelevant to the eventual result. Repeated IDs count once. Inputs contain strings; no other validation needed for these iterables.
Dirty nodes = changed plus all TRANSITIVE dependents in the FULL graph. If targets is None, required nodes = all nodes. Otherwise required nodes = targets plus all TRANSITIVE dependencies of targets (targets=[] means none). Rebuild set = dirty intersect required. Return exactly the rebuild set in topological order of its induced dependency graph, choosing at EACH step the ready node with lowest permanent rank (not FIFO order, not alphabetic). Clean prerequisites are assumed already built, so do not include them and do not let them block dirty nodes. Compute dirty propagation before restricting to required nodes.
explain(changed, node) returns None if node not dirty; else returns a list describing one path from a changed node to node along dependent edges. Choose SHORTEST number of edges first; ties by lexicographic sequence of permanent ranks of the entire path. A node in changed explains itself as [node]. Validate all changed IDs and node even if a candidate explanation was already found. No mutation by queries. Methods operate on the currently installed graph. Standard library only. Scale: DAGs with 10000 nodes, 30000 edges, including chains longer than Python's recursion limit; avoid enumerating all dependency paths and recursion-depth failures.
