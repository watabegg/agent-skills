## recovery manifest に必要な項目

新 run を作る前に、machine-readable な `RECOVERY-MANIFEST.json` を生成する。少なくとも次を含める。

- old namespace、run ID、phase、skill version
- integration branch と exact HEAD
- T050/T051 branch HEAD、tree SHA、candidate artifact digest
- Patch Review artifact の path と digest
- D005 から D008 の path と digest
- R005、G053、A001、A002 の path と digest
- T052 から T055 の task contract digest
- preserved worktree の path と clean/dirty status
- `do_not_resume_role_state: true`
- `import_as_evidence_only: true`
- 新 run の namespace と runtime digest

manifest は候補の内容を「合格」とは認定しない。どの evidence を移したかだけを証明する。
